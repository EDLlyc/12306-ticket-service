    \item \textbf{库存扣减与分桶模型}：基于 Redis Lua 实现库存原子预扣减，设计 Segmented Stock 分桶库存模型分散热点流量，降低高并发订票场景下的库存争抢与超卖风险。

\end{enumerate}
