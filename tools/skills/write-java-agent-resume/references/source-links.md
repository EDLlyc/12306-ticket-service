## Key Takeaways Encoded Into This Skill

- Java/backend JD tends to reward:
  core language depth, data structures, distributed systems, DB/cache/MQ, performance, stability, and production engineering.

- Agent/AI application JD tends to reward:
  framework usage only when tied to real systems, tool calling, workflow design, retrieval quality, evaluation, runtime architecture, and reliability.

- Resume writing guidance consistently rewards:
  tailoring to the role, strong action verbs, specific wording, result-oriented bullets, scannability, and honest quantification.
